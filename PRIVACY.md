# Privacy

Hermes Session Hub Web is local-first.

- No telemetry.
- No account or login.
- No cloud upload.
- No external assets.
- Diagnostics ZIP files are created only by explicit click and are redacted.
- Message text is not shown until the local user expands a session card.
- Skills search and preview responses do not include absolute local paths.

Writable app data is limited to `%LOCALAPPDATA%/HermesX/SessionHubStudent`.
